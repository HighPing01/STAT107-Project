# STAT107-Project

01_funct_DataCleaning.R: functions, one that converts height to centimeters and another that separates the "elite scorers".
CSV files (23_24.csv, 23_24Height.csv, 24_25.csv, 24_25Height.csv, 25/26.csv, 25/26Height.csv, 26/27.csv) are our data files with general nba data like name, height, ppg, etc.
STAT107_Project.RMD: our main file which encases our code and preliminary analysis. 
FinalReport.RMD: our report file that includes our knitted report with title, abstract, and other stuff.
